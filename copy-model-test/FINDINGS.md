# 12월·지정 상품 재실험에서 확인한 점

새 입력은 **랑드샤 베스트 티 4종 세트 / 12월 한 달**입니다. 크리스마스·가을·송년·신년을
각각 hero 1구좌로 비교했습니다. 가을은 12월 중 가을의 여운이라는 감성 콘셉트이고,
신년은 12월에 다가올 새해를 준비하는 콘셉트입니다. 실제 행사 계획을 확정한 것이 아닙니다.

## 실제로 실행한 모델과 결과

공식 Qwen GGUF 2종을 내려받아 Mac의 llama.cpp CPU에서 실행했습니다.
외부 추론 API나 인증 토큰은 로컬 생성에 사용하지 않았습니다.

| 모델 / 양자화 | 긴 입력 응답 / 기본 규칙 통과 | 짧은 단일 주제 입력 응답 / 기본 규칙 통과 | 현재 응답 시간 |
|---|---:|---:|---:|
| Qwen2.5 0.5B Instruct / Q4_K_M | 4 / 0 | 4 / 0 | 1.34~3.30초 |
| Qwen2.5 1.5B Instruct / Q4_K_M | 4 / 2 | 4 / 3 | 3.65~4.67초 |

각 칸은 주제별 한 번의 응답입니다. 첫 실행 8건과 입력을 개선한 실행 8건, 총 16건의 원문을
모두 보존했습니다. 입력 개선 후 결과만 REPORT에 표시하며 첫 결과는
`runs/december-local-long-prompt/`에 있습니다. 원문을 사람이 수정하거나 좋은 결과만 골라
덮어쓰지 않았습니다. 입력이 달라졌으므로 두 단계의 차이를 엄밀한 모델 성능 개선 수치로
해석하지 않습니다.

시간은 서버가 모델을 로드한 뒤의 HTTP 요청부터 응답까지입니다. 다운로드·모델 로드 시간은
제외하고, 서버의 공통 프롬프트 캐시가 이후 요청에 영향을 줄 수 있습니다. CPU 4스레드에서의
관찰이며 사내 PC의 속도나 기존 원격 BF16 모델과 직접 비교할 수 없습니다.

## 현재 소형 모델만으로 배포하기에는 부족합니다

**0.5B는 소형 기준선입니다.** 긴 입력에서는 입력 JSON을 되풀이했고, 짧은 입력에서도
크리스마스 제목에 입력하지 않은 ‘선착순 30% 혜택’을 만들었습니다. 나머지 응답도
상품명 누락이나 ‘12월 한 달’의 반복이 많아 문구 추천기로 쓰기 어렵습니다.

**1.5B는 더 읽을 만한 문장을 만들지만, 출처 활용과 사실 통제가 부족합니다.** 예를 들어
크리스마스 설명은 ‘크리스마스 선물로 티 타임 즐기세요’, 가을 설명은
‘가을의 여운을 풍기는 차세트’입니다. 다만 제목을 모두 상품명으로 채웠고,
신년 설명에는 확정되지 않은 ‘특가 할인’을 넣었습니다. 출처 설명도
‘참고한 표현 구조’라는 빈 양식 수준이어서 실제로 그 출처를 타당하게 참고했는지 확인하기 어렵습니다.

1.5B의 3건 기본 규칙 통과는 출처 ID·상품명·기간·숫자/혜택·길이 등의 검사 결과입니다.
상품명이 제목에 들어갔으면 사실 누락으로 처리하지 않고, 설명에 넣으라는 프롬프트 지침 위반을
별도 경고합니다. 송년의 명시적인 시즌 표현 부족과 빈 출처 설명도 경고로 남깁니다.
**추가 검토가 전혀 필요 없는 결과가 3건이라는 뜻은 아닙니다.**

긴 입력의 첫 1.5B 크리스마스는 주제 ID를 osulloc으로 바꾸고 새해 문구를 냈고,
송년은 가을 문구를 냈습니다. 이 관찰을 근거로 한 번에 다른 시즌 설명을 섞지 않고,
단일 주제와 오설록 발췌문 2개만 전달하도록 간소화했습니다. 전체 구좌용 프롬프트는 별도로 남겼습니다.

## 기존 모델을 새 조건으로 비교하지 못한 이유

Gemma 3n E4B·Gemma 3 12B·Qwen3-VL 4B는 12월 조건으로 실제 재호출했지만,
Hugging Face 읽기 토큰으로 인증한 뒤에도 무료 ZeroGPU 할당량이 없었습니다.
Qwen3 공식 데모의 4B·8B·14B도 서버 오류로 응답을 얻지 못했습니다.
그 오류를 새 문구나 모델 품질 실패 점수로 바꾸지 않았습니다.

새로 추가한 Gemma 2 2B·Llama 3.2 3B·Gemma 4 E4B 공개 데모 어댑터는 설정 준비까지만
완료했습니다. 이미 소진된 공통 GPU 할당량을 다른 Space로 우회하려고 계속 호출하지 않았습니다.
할당량이 회복되거나 별도 서버가 준비되면 같은 입력으로 실행할 수 있습니다.

이전 3종의 문구 11건은 상품·기간 미정 조건이었으므로 현재 소형 모델의 결과와
동일 조건 순위로 비교하지 않습니다. 해당 입력과 보고서는 `runs/baseline-category-only/`에 있습니다.

## 오설록 레퍼런스 보강

오설록 몰 메인을 최신 DOM으로 수집해 `osulloc-004`의 13개 섹션과 이미지·링크 관계로
추가했습니다. 진행 중 이벤트 3건은 이미 있었으므로 원본 ID를 보존하고 최신 상세/목록 DOM을
`reference/data/revisits/20261108/`에 보관했습니다. 현재 총 195페이지·988섹션입니다.

현재 소형 모델 요청에는 새 메인 배너와 관련 오설록 표현의 출처 ID·발췌문을 전달합니다.
과거 ‘블랙프라이데이 50%’는 스타일 참고 자료이며 12월 행사 혜택이 아닙니다.
입력 레퍼런스를 전달했다는 사실, 모델이 유효한 출처 ID를 냈다는 사실만으로 의미적으로
충실히 참고했다고 단정하지 않습니다.

- 모델 출력에는 상품명·기간·혜택 검증을 적용하고, 담당자가 초안을 검토해 확정하도록 연결합니다.
- 사내 기기 선정 후 실제 배포할 양자화 모델로 품질·메모리·속도를 다시 측정합니다.

현재 자동 검사 15개와 기존 19 URL·신규 오설록 메인의 구조 검증이 통과했습니다.
이는 프로그램 검증이며 생성 문구 전체가 승인됐다는 뜻은 아닙니다.
